# 🧟 좀비 수학 대작전

5학년 2학기(2022 개정) 수업용 모둠 협동 게임 — 4. 소수의 곱셈 / 5. 직육면체 / 6. 평균과 가능성

- 학생 화면: `index.html` (모둠·번호만 입력, 로그인 없음)
- 교사 화면: `teacher.html` (단원 고르기, 시작, 모둠별 진행 상황, 단계 넘기기, 내보내기)

## 흐름
대기(게임 설명) → 1라운드(각자 3문제) → 파괴수 보스전(철 장비) → 2라운드(각자 3문제) → 드래곤 보스전(다이아몬드 장비) → 순위 + 승리 스킨 고르기

보너스: 3문제를 먼저 끝낸 학생은 보라색 강한 좀비의 보너스 문제(틀려도 하트 그대로). 3개 맞힐 때마다 아이템 (1라운드: 방패·황금 사과 / 2라운드: 활과 화살·힘의 물약)

## 파이어베이스 연결
`js/config.js`의 `firebaseConfig`가 비어 있으면 **체험 모드**(한 컴퓨터의 탭끼리만 연결)로 동작합니다.
실시간 데이터베이스(Realtime Database)를 만들고 규칙은 아래처럼 둡니다.

```json
{
  "rules": {
    "zombieMath": { ".read": true, ".write": true }
  }
}
```
